# Decisions Log

Architectural and implementation decisions made during the build.

## Phase 1

| # | Decision | Rationale |
|---|---|---|
| D1 | ESLint 8 (not flat config) | `@typescript-eslint` plugin works best with legacy config format in eslint 8. eslint 9 flat config support for plugins is still spotty. |
| D2 | `mulberry32` as seeded RNG | Simple, fast, 32-bit state. Good enough for procedural textures. Seed = `42` for reproducibility. |
| D3 | Geodesic shader from `sun-collapsed.html` as the single source | Per amendment #6: the collapse file's geodesic loop includes `sunSurf()` and `uR/uHeat/uDisk` uniforms. With defaults `uR=1, uHeat=1, uDisk=1`, the star is disabled (uR ≤ 1.02 guard) and the loop matches pure Gargantua behavior. One loop, two experiences. |
| D4 | `ROUT` as a uniform (default 15) | Per amendment #8: allows solar-system mode to clamp to 9 without duplicating the disk shader. |
| D5 | Texture color-space metadata stored in `textures-meta.json` | Generated by `extract-textures.mjs`. Body `textures.ts` files reference this. Linear for normals/roughness/bump; sRGB for albedo. |
| D6 | Playwright with SwiftShader for parity screenshots | `--use-angle=swiftshader --enable-unsafe-swiftshader` flags enable headless WebGL. No pixel-perfect match required; logged differences only. |
| D7 | `?freeze=1` URL parameter freezes `clock.elapsedTime` at 0 | Enables deterministic screenshots. Checked via `URLSearchParams` in render loop. |
| D8 | Deploy target is Vercel with SPA rewrites | `vercel.json` with `"rewrites": [{"source":"/(.*)", "destination":"/index.html"}]`. |
